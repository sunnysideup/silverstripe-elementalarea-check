# tl;dr

Just run:

```shell
vendor/bin/sake dev/tasks/elemental-area-check
```

There are two params you can add:

- `quicktestonly`: just shows you the current situations
- `dryrunonly`: run all, but dont make any real changes

e.g.

```shell
vendor/bin/sake dev/tasks/elemental-area-check quicktestonly=true
```
